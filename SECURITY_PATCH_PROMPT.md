### src/server/routes/api.ts

#### 2. Record ownership taken from the request instead of the session (IDOR) — `src/server/routes/api.ts:372:7`

- **Rule:** `VSB-AUTH-004` (unguarded-routes)
- **Severity:** critical · **Confidence:** medium
- **CWE:** [CWE-639 — Authorization Bypass Through User-Controlled Key](https://cwe.mitre.org/data/definitions/639.html)

`projectId` is taken from request data and may be used for an ownership decision.

**Vulnerable code**

```ts
projectId: t.projectId || null,
```

**Required change**

1. Derive the owner from the verified session (`session.user.id`, `auth().userId`, `req.user.id`) — never from request input.
2. Add the ownership predicate to the database query itself (`where: { id, userId: session.user.id }`) so a wrong id is a no-op rather than a leak.
3. Do not accept `userId` in the request body at all; validate the schema with `.strict()` so extra fields are rejected.
4. Return 404 (not 403) for records the caller cannot see, to avoid an enumeration oracle.

**Illustrative remediation example (adapt to the project)**

```ts
const session = await auth();
await db.orders.delete({ where: { id, userId: session.user.id } })
```

### src/server/routes/uploads.ts

#### 18. Filesystem path built from request data — `src/server/routes/uploads.ts:176:8`

- **Rule:** `VSB-AI-012` (ai-vulnerabilities)
- **Severity:** high · **Confidence:** high
- **CWE:** [CWE-22 — Improper Limitation of a Pathname to a Restricted Directory](https://cwe.mitre.org/data/definitions/22.html)

A filesystem path is built from request-controlled data.

**Vulnerable code**

```ts
fs.writeFileSync(fullPath, req.file.buffer, { mode: 0o600 });
```

**Required change**

1. Reduce the input to a basename (`path.basename`) and validate it against `^[A-Za-z0-9._-]+$`.
2. Resolve the final path and assert it is still inside the intended root: `resolved.startsWith(rootResolved + path.sep)`.
3. Prefer opaque ids over filenames: store the object key in the database and look it up server-side.
4. Serve user content from object storage rather than the local filesystem.

**Illustrative remediation example (adapt to the project)**

```ts
const safe = path.basename(req.params.name);
if (!/^[\w.-]+$/.test(safe)) return res.sendStatus(400);
res.sendFile(path.join(UPLOAD_DIR, safe));
```
